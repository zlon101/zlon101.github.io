# 思维

思想指导行为，行为反馈给思考，慢慢调整思想

想要摒弃那些无意义、消极的想法，就用积极有意义的想法填充大脑🧠，因为大脑的短时记忆和单焦点特点，大脑在某个时刻只能思考一件事

实验证明大脑会无意识的处理信息
- 所以看书、学习的休息间隙可以放空大脑，不要在输入其他信息干扰大脑，让大脑自动处理刚刚输入的信息

大脑会自动忽视稳定的信息
- 所以反复的阅读效果不明显，要增加学习的难度

我们为什么要做一些“看似无用”并且有难度的事情？
- 通过成功完成有难度的事情，你可以证明自己可以做困难的事情，也会逐渐建立起对自己能力的自信

你需要对事情发生的原因有深厚的兴趣，经过长年累月的积累，这种习惯会逐步提升你关注现实的能力 --- 查理.芒格

**语言的力量**

如果想实现某个愿望，首先应当下定决心，“我一定要实现这个愿望”。静静地坐在桌前自言自语：“我要斩断我们家贫穷的尾巴，我要变成受人尊敬的富人，我要守护我的家人和我所爱的人。我要这样活着。”说出这些话的瞬间，话语就具有了力量，就会指引人朝这个方向付出行动。如果抑制语言，那么想法就会闭塞，行动就会受限。相反，如果敞开了话语，想法也会随之打开，行动就能实现愿望。

人类的心思体现在话语当中，无情的语言难以感动或改变他人；不含感情的交流只会留下理论和逻辑成分，我们不会仅因为某人会说话或逻辑性强就尊敬他。如果他充分体现出真诚，即便他的想法和意图与我们不同，我们也会对他表示尊敬。

网络上基于文字的沟通，取消了大量的神态、语气、肢体语言，相当于减少了超过一半的信息量。这导致什么呢？大量的误解。我们更加容易因一言而不合，更加轻易地因为别人的一句话而愤怒。所以，文字沟通或者聊天的时候可以配合表情包，减少误会

**行动的重要性**

并不是先有一件事情、再被我们找到，而是我们先去行动，从行动中获得反馈，再把它升级成为我们的兴趣和事业。

对行动导向的人而言，去做可能会出错，但不去做就永远不知道深浅。因此，他们会把行动作为默认选项，通过行动去改变现在所处的状态，而不是等状态更好了，再去行动。


# 计划

分步思考、短期规划、快速行动，在行动中进行试错，收集反馈。（小步快跑--快速迭代--反馈调整）

- 最重要的是避免遗忘目标，要时刻提醒自己。

- 每隔几个小时查看笔记本。在养成新习惯的初期，学习实践新的方法时，高频的提醒自己，加深印象。

- 让大脑在学的时间足够长但没有达到疲劳之前停止（学习的第二个高潮，感觉良好的时候），以一种快乐的状态结束学习。

# 习惯

养成严格内化的习惯，使我们能更轻松的进入深度工作的状态并保持更长的时间
- 比如：开始工作前整理大脑，清除干扰项，清除内存


如何才能坚持养成一个习惯？
- 最关键的诀窍就是不要坚持，而是通过不断地【微调】、设计、尝试，找到一个既比过去好一点，又能令自己感到舒适的状态
- 想常年保持做同一件事，你必须对这件事没有抵触，换言之，永远不要指望靠“坚持”来实现这点，因为一旦这件事有半点痛苦，从长期来看，你都无法坚持(好奇心)。
- 运动的物体趋向于运动，静止的物体趋向于静止。与其在考虑一件事该不该做，不如先动手做10分钟。 

丰富生活中的兴趣和刺激源
- 一个健康的心理，每天应该做三种不同类型的事情。和吃东西一样，什么都吃一点，避免一段时间内只做一件事？

养成好的习惯并持之以恒，身体会适应的。

# 情绪

- 我永远都无法完全准备好；
- 一个人看不惯的东西、人和事越多，这个人的境界就越低，格局也就越小；
- 去做你害怕做的事，去见你害怕见得人，这就是成长；
- 当面对一件事，客观上对你很重要，但心理上你却感到害怕时，赶紧去做它，做到感觉良好的那个点时---立即停止。下次再遇到类似的事情就没有那么害怕了；

  - 有一件讨厌但非做不可的事，在讨厌他的时候去做，做到喜欢的时候停止；

- 当你感到这些情绪时，试着不要抵抗和批判它们，而是感受这些情绪背后的信息，它们传递的是什么？尽量不要让情绪控制。


- Doing is better than perfect。迭代工作，期待完美收工会令人窒息；做完事情，要胜过完美收工。




- 动漫有感：不能靠毅力去长期做一件事，看动漫无论什么环境、影响都能持续，心情不好就看动漫，如果变为心情不好就看书！！！无敌啦。看书学习，安静的环境是必要的吗；
- 所以，把“信息”变成“资源”，是一种需要刻意培养的思维习惯。不要想着把买的书都看完，这样没有价值，把它们当成资源，只在需要的时候，去看需要的内容就好(查书而非看书)，笔记也是一样。看完一本书，没必要全部记下来，追求没有缺漏 —— 你只需要记下“对我有用的信息”就可以了。
- 当下的痛苦都是源于对现状的抗拒和不接受，思维抗拒，情绪也抗拒。在这种状况下，努力和焦虑在一些时间里就会相伴出现。
  - 如何调节呢？接受你拥有的，利用好你拥有的。有什么做什么，有什么用什么；做什么都做好，用什么都用好。
- 利用模式转换，将被动的克服一件事变为**主动**的去做、去解决，获得主动权。克服需要消耗能量(身体\情绪)，不好的事情才需要克服，如何把不好的事情转变为对我有利的事情？利用巴甫洛夫的狗和老人的糖果，获取主动权。
- 焦虑的反面是具体、明确

患得患失，太在意从前，又太担心将来。昨天是段历史，明天是个谜团，而今天是天赐的礼物🎁，像珍惜礼物一样珍惜今天
- 明天是未知的，对明天的焦虑并不会让明天变好，只会让当下变糟

对于不可控的事情，我们要保持乐观和自信，对于可控的事情，要保持谨慎和节制。
- 对于不可控的事情，焦虑和恐惧于事无补。焦虑改变不了明天，反而影响今天的心情。
- 对于可控的事情（能不能好好利用今天的时间就是可控的），要谨慎和节制

**避免内耗，遇到不好的事情时应该怎么办？**

你要向客户、领导、合作伙伴讲一个坏消息，你可能会很担忧，在心里不断想象他们勃然大怒或者失望的样子。但这种想象只会进一步加剧你的担忧，让你困在内耗之中，对解决问题是毫无帮助的。更好的做法是：想象他们可能会有什么样的反应，会提出什么问题，会说出什么样的话。再针对他们可能的反应思考我可以做些什么来应对，尽可能缓和场面，减少负面的后果。通过思考“我能做什么”，并在心里预演，当你去行动的时候，就可以无须再动脑思考，直接调用预设好的框架来回应，从而减轻心理负担和认知负荷。

最关键的点是要把你的思考角度从沉浸、忧虑、想象中及时抽离出来，转移到行动上，专注地去思考：有哪些是我能控制的？我可以做些什么？我应当采取哪些步骤去行动？

多想想有没有别的可能性，还可以做些什么来改变现状


**出现负面情绪时应该怎么办？**
- 每当你产生负面情绪之后，向内剖析引发自己产生情绪的外部事件是什么？你是如何解读它的？内心深处的信念是什么
- 找出内在的信念之后，试着换一个更好的信念去修正它。问自己它有没有另外一种可能性？如果事情是这样，而不是我最初理解的那样，是否能够成立？
- 比如，当你坚信的观点被别人反驳时，你可能会火冒三丈，为什么呢？很可能是因为这样一个信念：“我相信的事情就是真实的，是不容置疑的，质疑它的人一定别有用心，因此他是我的敌人。



# 金字塔原则

**结构化思考和表达**

任何事情都可以归纳出一个中心论点，而此中心论点可由三至七个论据支持，这些一级论据本身也可以是个论点，被二级的三至七个论据支持，如此延伸，状如金字塔。

核心是结论先行，然后分论点支持，每个论点再展开论据。

应用场景：写作、汇报

**金字塔原理的核心规则**

1. **结论先行**
   将核心结论或关键信息放在最前面（金字塔顶端），再逐层展开支撑论据，形成“自上而下”的逻辑结构。这种方式让读者/听众第一时间抓住重点。
2. **归类分组**
   将复杂信息按逻辑关系分组，每一组思想必须属于同一范畴（如时间顺序、结构拆分、重要性排序等）。
3. **逻辑递进**
   每组思想需按逻辑顺序排列（如演绎推理、因果关系、问题-对策等），确保上下层之间形成紧密的支撑关系。

**金字塔结构的组成**

- **塔尖（顶层）**：核心结论、中心思想或关键建议。
- **中间层**：支撑结论的主要论点或分论点。
- **底层**：具体的数据、案例、事实等细节论据。



**应用场景**

1. **写作与汇报**
   例如：商业报告中先提出结论，再分点阐述原因；邮件开头点明目的，再展开细节。
2. **解决问题**
   拆解复杂问题时，先定义核心问题，再逐层分析子问题及解决方案。
3. **演讲与沟通**
   用“总分总”结构，先抛出观点，再用逻辑清晰的论据支撑。



**为什么有效？**

- 符合人类思维习惯：大脑更容易记住层级分明、逻辑连贯的信息。
- 提升效率：避免冗长铺垫，直接传递关键信息。
- 增强说服力：通过层层支撑的论据，让结论更可信。

**案例示范**

**低效表达**：
“我们发现用户留存率下降了5%，可能是因为产品功能不够完善，也可能运营活动不够吸引人，还有客服响应速度变慢……”
（信息零散，缺乏重点）

**金字塔结构表达**：

- **结论**：用户留存率下降5%的主要原因有三方面。
  - **产品功能**：近期未更新核心功能，用户需求未满足。
  - **运营策略**：活动频率降低，用户参与度下滑。
  - **服务质量**：客服响应时间延长，投诉率上升。

**如何练习金字塔原理？**

1. 在写作或演讲前，先用纸笔画出金字塔结构。
2. 自问：“我的核心结论是什么？如何用3个论点支撑它？”
3. 检查逻辑是否满足MECE原则，避免重复或漏洞。

掌握金字塔原理，能显著提升逻辑思维能力，让复杂问题变得清晰易懂。如果想深入学习，推荐阅读芭芭拉·明托的《金字塔原理》原著。

**证实偏见**

如果一个人对婚姻持悲观态度，那么当他看到失败的婚姻案例，他就会更加笃信自己的立场，并更容易向身边的人传播，但那些结婚后仍然非常幸福的案例就被他下意识地忽略了。这就叫“证实偏见”。你持有什么立场，就总是更容易接受与你的立场相一致的信息，下意识忽略那些不一致的信息。
